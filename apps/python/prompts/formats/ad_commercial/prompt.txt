──────────────────────────────────────────────────────────────────────
STRUCTURE — MANDATORY (this is what makes it read as an AD, not a rant)
──────────────────────────────────────────────────────────────────────
1. HOOK — name the relatable problem or pain point. type: "hook".
2. AGITATE — make the problem feel urgent, costly, or embarrassing. type: "tension".
3. PRODUCT REVEAL — introduce the product/solution by name. type: "payoff" or
   "truth". This is usually BOTH the POSTER BEAT and the SILENT BEAT below —
   a real ad's voiceover often pauses right here and lets the music carry
   the reveal.
4. 2-3 FEATURE BEATS — fast, one concrete benefit each, no filler. type: "insight".
5. SOCIAL PROOF — one testimonial-style or credibility line. type: "truth"
   (the composer already turns truth/payoff beats into quote_card/comparison
   on its own — no archetype override needed for this beat).
6. PRICE / CTA CLOSE — the offer and the ask, together. type: "cta". Often
   ALSO a POSTER BEAT (price/offer as the headline). Fast or explosive pace.

Beat count 6-10 — use only as many FEATURE beats as the product genuinely
has distinct benefits for; don't pad.

──────────────────────────────────────────────────────────────────────
POSTER BEATS — set "archetype": "poster_card" directly on the beat
──────────────────────────────────────────────────────────────────────
Real ads have "poster" pages — one bold headline, one supporting line, held
statically like a print-ad panel, not a spoken caption. Use this on 1-2
beats total (usually PRODUCT REVEAL and/or the PRICE/CTA close):
  - "keyword" becomes the big headline — short, 2-5 words: the product
    name, or the offer itself (e.g. "40% OFF TODAY", "MEET AURA").
  - "text" becomes the smaller supporting line underneath. Still write a
    real sentence — it's shown on screen, and is ALSO the spoken line
    unless this beat is silent.

Example:
  {{ "keyword": "40% OFF TODAY", "text": "Every plan, every feature, one weekend only.",
     "archetype": "poster_card", "type": "cta", ... }}

──────────────────────────────────────────────────────────────────────
SILENT BEATS — set "silent": true
──────────────────────────────────────────────────────────────────────
Real ads pause the voiceover under a dramatic product shot and let the
MUSIC carry the moment. Use "silent": true on AT MOST ONE beat — almost
always the PRODUCT REVEAL, never the hook or the close:
  - Still write "keyword" and "text" — they're shown on screen (especially
    when this beat is also poster_card), just never spoken. "text" can be
    much shorter than the usual 10-25 words here, even a few words or
    empty — it is not read aloud and not counted toward the word budget.
  - Optionally set "silent_duration_s" (a number, e.g. 2.5) for how long
    the beat holds before the next one starts. Omit to use the default.
  - Never mark more than one beat silent — most of the ad still needs a
    voice carrying it.

Example:
  {{ "keyword": "INTRODUCING AURA", "text": "", "silent": true, "silent_duration_s": 3,
     "archetype": "poster_card", "type": "payoff", ... }}

──────────────────────────────────────────────────────────────────────
TONE
──────────────────────────────────────────────────────────────────────
Sound like a real ad, not a lecture. Direct, confident, a little urgent.
Name the product. Use "you". Short sentences on the hook/agitate/CTA beats;
the feature beats can breathe slightly more.

BANNED PHRASES — generic ad-copy filler that reads as fake: "industry-leading" /
"revolutionary" / "game-changing" / "unlock your potential" / "take it to the
next level" / "in today's world" / "here's the thing".

──────────────────────────────────────────────────────────────────────
VARY THE CLOSE — don't default to the same CTA every time
──────────────────────────────────────────────────────────────────────
A discount isn't the only way to close. Pick whichever actually fits the
product instead of reaching for "X% off" by default:
  - Discount/urgency: "40% off today", "first 100 orders only"
  - Risk reversal: "money-back guarantee", "try it free for 14 days"
  - Social proof: "join 10,000 others who switched"
  - Plain availability: "available now", "ships this week"
The PRODUCT REVEAL keyword should vary too — not always "MEET X" — try
naming what changes instead ("NO MORE BRAIN FOG", "YOUR NEW MORNING").

──────────────────────────────────────────────────────────────────────
GLOBAL FIELDS — pick one value per field based on the product.
──────────────────────────────────────────────────────────────────────
- theme/music_mood/voice_style/camera_style: the visual and sonic register
  that matches the product category (a premium product reads luxury_minimal
  + cinematic; a tech/app product reads tech_hud/tech_blue + dynamic).
- subject: the literal, photographable noun at the centre of the product —
  the anchor every visual_query builds on. The physical product itself if
  it has one; the nearest common concrete proxy if it's a service/app
  (an app → "phone screen app"; a service → the thing the service touches).

──────────────────────────────────────────────────────────────────────
PER-BEAT VARIETY — MANDATORY
──────────────────────────────────────────────────────────────────────
⚠ A stiff, repetitive render reads as a bad ad. Across the full script:
   1. Use at least 3 different `camera` values total
   2. Use at least 2 different `pace` values total
   3. Use at least 2 different `layout` values total
   4. Use at least 2 different `background` values total
   5. Never repeat the same `camera` for 3 consecutive beats
   6. Never repeat the same `layout` for 3 consecutive beats

──────────────────────────────────────────────────────────────────────
VISUAL QUERY — REQUIRED, must return a CONTEXTUAL image
──────────────────────────────────────────────────────────────────────
Image search is LITERAL. It does not understand emotion or metaphor.

RULES (all mandatory):
1. SAME-DOMAIN CONCRETE NOUN. Every visual_query must be a concrete,
   photographable noun from the product's domain — the literal thing on
   screen. It does NOT have to repeat the global `subject` string itself:
   prefer whatever noun is closest to THIS beat's specific content (the
   product in use for a feature beat, a person's reaction for the social-
   proof beat) over reusing the same subject phrase beat after beat —
   repeating it every beat produces one narrow, generic stock genre instead
   of each beat's own moment.
2. Then add AT MOST 1-2 VISUAL modifiers only: lighting, angle, setting.
3. BANNED — emotions and abstractions: "solitude", "journey", "powerful",
   "freedom", "success", "abstract". These return generic/nature stock.
4. 2-4 words. Concrete + visual. No mood.

Template: [beat-specific noun, or subject as fallback] + [setting or lighting]

──────────────────────────────────────────────────────────────────────
INTENSITY — 0.0 to 1.0, REQUIRED on every beat
──────────────────────────────────────────────────────────────────────
  hook:        0.85 - 0.95
  tension:     0.65 - 0.80
  payoff/truth (product reveal): 0.55 - 0.75 (lower if also silent — let
               the music carry it, not camera shake)
  insight (features): 0.55 - 0.70
  climax:      0.90 - 1.00
  cta:         0.80 - 0.95

──────────────────────────────────────────────────────────────────────
EMPHASIS WORDS — one per spoken sentence (skip on a silent beat's text)
──────────────────────────────────────────────────────────────────────
Wrap ONE word/short phrase per sentence in *asterisks* — the word the
audience should land on. Example: "Most cleaners just *hide* the smell."
